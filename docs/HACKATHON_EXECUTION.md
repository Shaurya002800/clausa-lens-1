# Hackathon Execution

## Time model
Nominal event duration: 48 hours.
Engineering budget: approximately 36 effective hours after reviews, checkpoints, presentations, integration, and interruptions.

## Operating principle
Prioritize one reliable vertical slice over broad but unfinished platform features.

## Sequence
1. Freeze HLD and contracts.
2. Build demo failure system.
3. Capture normalized evidence.
4. Build propagation graph.
5. Compile Replay Capsule.
6. Reproduce baseline failure in isolation.
7. Add one intervention path.
8. Compare executions.
9. Build visualization.
10. Harden demo and pitch.

## Scope-control rule
Do not add a feature unless it materially strengthens:
- reproducibility,
- causal differentiation,
- safety,
- demo clarity,
- judging differentiation.
