# E0-E3 Execution Plan

## E0 — Contract Freeze
Goal: make parallel work safe.

Deliverables:
- repository structure
- normalized event schema
- propagation graph schema
- Replay Capsule schema
- intervention schema
- replay result/diff schema
- System Pack interface
- golden demo scenario

Exit criterion:
Three developers/agents can implement independently without inventing conflicting contracts.

## E1 — Evidence to Graph
Goal: turn a real demo incident into a useful propagation graph.

Deliverables:
- demo distributed failure path
- capture hooks
- normalized evidence store
- graph construction
- incident inspection endpoint

Exit criterion:
A known incident produces a stable, inspectable graph.

## E2 — Capsule to Baseline Replay
Goal: reproduce the incident safely.

Deliverables:
- capsule compiler
- isolated replay runtime
- dependency interception/mocking
- reproducibility gate
- replay event capture

Exit criterion:
The original failure is reproduced without real external side effects.

## E3 — Counterfactual Differential
Goal: demonstrate causal experimentation.

Deliverables:
- one-variable intervention engine
- at least two useful interventions
- baseline vs counterfactual comparison
- causal-role explanation
- visualization/demo flow

Exit criterion:
Changing one approved variable produces a visible, interpretable execution differential.
